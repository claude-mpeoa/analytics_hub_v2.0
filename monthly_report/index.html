    RAG rules and formulas

    The colours are not hardcoded. They are calculated every time the CSV data is loaded.

    Formula driven
    Sales vs target RAG: Green when actual / target >= 100%, amber when >= 95%, red when below 95%.
    ROI RAG: Green when ROI >= 10x, amber when ROI >= 5x, red when below 5x. Organic channels with zero spend are shown as neutral.
    Cost RAG: Green when actual cost is <= benchmark, amber when within 10% above benchmark, red when more than 10% above benchmark.
    Contact rate RAG: Green when contacted leads / leads >= 80%, amber when >= 70%, red when below 70%.

    Place this folder in Git and update the CSV files in the data folder. Serve the folder through GitHub Pages, a web server, or a local server for browser CSV loading.
