How to log a Web Dev Ticket

Use this guide when submitting a request through the Virgin Active Web Dev Workflow Portal. The ticketing form has four steps: overview, classification, business objective, and scope and assets.

01. Request Overview

Start from the Log Request tab

At the top navigation, select Log Request. You will land on the overview page where the basic ticket details need to be captured.

Request Title / Headline

Enter what the ticket is about. This becomes the ticket name.

Requestor Details

Add your full name, work email, department, and market region manually.

Saved Requestor Details

After your details have been added once, they can be selected from a dropdown in future.

Campaign / Initiative

Enter the campaign name, or mark it as Not Applicable for bug fixes, typo fixes, and similar requests.

Go Live Date and Priority

Select the requested go live date and priority. High priority requests will be assessed accordingly, but delivery before the requested go live date cannot be guaranteed because other high priority tickets may already be queued.

02. Classification

Define the request type

Select the Request Type that best describes what needs to be done. This helps the developer understand the type of work being requested and route the ticket correctly.

Examples

Landing page changes, homepage updates, banner swaps, copy updates, image updates, campaign launches, GA4 tracking, SEO metadata updates, bug fixes, or form updates.

03. Business Objective

Explain the purpose and impact

Purpose of the Request

Explain why the ticket is being logged and what the request will fix or improve.

Target KPI / Metric

Add what the change is expected to drive, such as conversions, user experience, sales, or another measurable outcome. If it is just a fix, enter N/A.

Priority Context

Explain why you selected the priority level. This gives the developer context when comparing the request with other active tickets.

04. Scope and Assets

Provide the exact requirements

URLs Impacted

Add the URL that needs to be fixed, or the suggested URL for a new page. If more than one URL is affected, separate them with commas.

Change Requirements

Provide step-by-step instructions explaining what needs to be done on the request.

Asset Status and Asset Link

If you have images, videos, or text content, email them to claude.mpeoa@virginactive.co.za, or place them in a folder and paste the Drive or cloud folder link in the Asset Link field.

Additional Info

Use this field for anything you may have missed in earlier steps. You can also use Previous Step to go back and edit earlier information.

Submitting the Request

What happens after all required fields are completed

Success Message

A confirmation message appears when the request has been submitted successfully.

Ticket Number

There is no need to memorize the ticket number. You can find your tickets later using your work email address.

Review Details

The ticket stores the request details, current status, notes, and reference number.

Tracking Your Ticket

Use the My Tickets section

Open My Tickets and search using the email address you used when logging the request. Select the ticket to view more information.
