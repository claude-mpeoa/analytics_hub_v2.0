Git Repository & GitHub Pages Sync Guide

How to keep this app automatically reading the excel/csv file in the same folder.

Setup Steps (Completely Free & Zero Setup):

  1. Create a new Git Repository (e.g. on GitHub).
  2. Place this index.html inside the repository.
  3. Export your raw Meta Ads metrics and save/rename it exactly as Meta-Ads-Extract (17).csv in the same directory.
  4. Go to repository Settings -> Pages and select your main/master branch to build.
  5. Your live site will now fetch the CSV directly from the repository on load!
